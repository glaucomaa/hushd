# MOMENTUM 4: multipoint с Linux

**Среда:** firmware 3.38.3, GAIA 3.1, iOS Smart Control, Linux BlueZ 5.87/PipeWire, macOS.

**Симптом:** при переключении Mac → Linux через Smart Control звук работает,
но приложение сообщает `failed to connect`. После перезапуска оно видит Linux,
но обратное переключение на Mac может не работать.

**Трасса:**
- `0x1402` для Linux → success `0x1502`; уведомления connected `0x1484` нет.
- Без перезапуска приложение может подключить Mac без отключения Linux → `0x06`.
- После перезапуска `0x1403` для правильного индекса Linux → ошибка `0x03`.
- В том же состоянии Linux-клиент получает `0x03` даже при отключении iPhone.

**Контроль:** баг воспроизводится без нашего демона. Полный разрыв и подключение
со стороны Linux восстанавливают GAIA-переключения. BlueZ Connect без разрыва,
отключение HFP и пересоздание A2DP не помогают.

**Workaround:** `m4d` автоматически переподключает Linux после внешнего
Bluetooth-подключения. Полный цикл Mac ↔ Linux проверен. Smart Control всё равно
показывает ложную ошибку и требует перезапуска. Причина дефекта не установлена.
